### 问：mysql我想删除名为study的数据库，然后重新创建

```SQL
-- 1. 删除旧数据库（如果存在）
DROP DATABASE IF EXISTS study;

-- 2. 重新创建数据库（推荐指定 utf8mb4 字符集）
CREATE DATABASE study 
  CHARACTER SET utf8mb4 
  COLLATE utf8mb4_unicode_ci;

-- 3. 切换进入新创建的数据库
USE study;
```

**关键说明**

- **数据不可逆**：`DROP DATABASE` 会彻底清除 `study` 库内的所有数据表和记录，执行前请确认无需备份。
- **`IF EXISTS`**：避免在数据库不存在时抛出错误报错。
- **`utf8mb4`**：相比旧版的 `utf8`（仅支持 3 字节），`utf8mb4` 完整支持 4 字节字符（包括 Emoji 和特殊生僻字）。
