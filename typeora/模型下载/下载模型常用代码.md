# 下载模型常用代码

```python
from modelscope import snapshot_download, AutoModel, AutoTokenizer 
import os 
model_dir = snapshot_download('ZhipuAI/glm-4-9b-chat', cache_dir='/root/autodl-tmp', revision='master')
```

这段代码使用了 `modelscope` 库来下载并缓存一个预训练模型。下面是逐行的解释：

```python
from modelscope import snapshot_download, AutoModel, AutoTokenizer
```

- `snapshot_download`：这是 `modelscope` 库中的一个函数，用来从 ModelScope 存储库中下载模型并缓存到本地。
- `AutoModel` 和 `AutoTokenizer`：这些是 `modelscope` 库中的类，通常用于自动加载模型和对应的分词器（Tokenizer）。在这段代码中，虽然没有使用这两个类，但它们的导入通常表示后续代码可能会用到它们来加载模型和处理文本。

```python
model_dir = snapshot_download('ZhipuAI/glm-4-9b-chat', cache_dir='/root/autodl-tmp', revision='master')
```

- `snapshot_download`：从指定的 `modelscope` 仓库下载模型快照并缓存到本地。
  - `'ZhipuAI/glm-4-9b-chat'`：这是模型的名称，表示你要下载的具体模型。在这个例子中，模型是 **GLM-4-9B-chat**，是一个由 **ZhipuAI** 提供的 9B 参数大小的聊天生成模型。
  - `cache_dir='/root/autodl-tmp'`：这是一个可选参数，指定了模型下载后的缓存目录。模型文件会下载并存储到 `/root/autodl-tmp` 目录下。如果没有指定，`modelscope` 会默认使用一个路径进行缓存。
  - `revision='master'`：这是指定要下载的模型版本或分支。在这个例子中，指定的是 `master` 分支，表示下载该模型的最新稳定版本。

```python
model_dir = snapshot_download('ZhipuAI/glm-4-9b-chat', cache_dir='/root/autodl-tmp', revision='master')
```

- `model_dir`：`snapshot_download` 函数会返回模型的存储路径，即缓存模型文件的本地路径。通过将返回值赋给 `model_dir`，你可以后续使用这个路径来加载模型或进一步操作。

### 总结：

这段代码的作用是从 **ModelScope** 上下载名为 `glm-4-9b-chat` 的预训练模型，并将模型文件缓存到指定的路径 `/root/autodl-tmp`。下载完成后，模型文件的路径会存储在 `model_dir` 变量中，后续可以使用该路径进行模型加载等操作。

# 如果运行了一次这段代码，将模型下载到了文件夹中，再次运行还会重复下载吗?

如果你再次运行这段代码，**`snapshot_download`** 函数不会重复下载模型，前提是模型已经被下载并且存在于缓存目录中。

`modelscope` 库在下载模型时会检查指定的 `cache_dir` 目录。如果目录中已经有缓存的模型文件，`snapshot_download` 会直接返回该文件的路径，而不会重新下载模型。

### 具体工作原理：

- `cache_dir='/root/autodl-tmp'`：这是缓存目录。如果该目录下已经存在所需的模型文件，`snapshot_download` 会跳过下载过程，直接使用缓存的文件。
- 如果模型文件不存在，或者文件被删除或损坏，`snapshot_download` 会重新从 ModelScope 上下载该模型。

### 结论：

如果你第一次运行时成功下载了模型并且模型文件已存在于指定的缓存目录，再次运行该段代码时，不会重复下载模型，而是直接返回已缓存的模型路径。
