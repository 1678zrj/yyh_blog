## 二、CPU 物理结构（最重要）

### 1️⃣ CPU 数量与核心数

```text
座：                  2
每个座的核数：        12
每个核的线程数：      2
CPU：                 48
```

解释：

- **2 颗物理 CPU**
- 每颗 CPU **12 个物理核**
- 每个物理核 **2 个线程（超线程）**
- 总逻辑 CPU 数：`2 × 12 × 2 = 48`

📌 关键区分：

- **物理核心数：24**
- **逻辑核心数（lscpu 的 CPU 数）：48**

在做性能评估 / 并发设计时，这个区分非常重要。

## 三、CPU 型号与定位

```text
型号名称：Intel(R) Xeon(R) Silver 4310 CPU @ 2.10GHz
```

这是 **第三代至强（Ice Lake）Silver 系列**：

- 主频：**2.10 GHz（基频）**
- 定位：
  - Silver ≠ 高性能单核
  - 更偏向 **多核并行、稳定运行、服务器负载**

⚠️ 注意这行：

```text
CPU MHz：990.121
```

这不是性能低，而是：

- CPU 处于 **空闲 / 节能状态**
- 实际负载上来会自动升频（Turbo）

## 四、NUMA 架构（多人服务器非常关键）

```text
NUMA 节点：           2
NUMA 节点0 CPU：      0,2,4,...,46
NUMA 节点1 CPU：      1,3,5,...,47
```

解释：

- 每颗物理 CPU = 一个 NUMA 节点
- **CPU + 本地内存 是一组**
- 访问“远端 NUMA 节点内存”会更慢

📌 这对你意味着：

- **单进程大内存 / 多线程任务**
  - 可能会受到 NUMA 影响
- 深度学习 / 推理 / 特征抽取任务：
  - 如果 CPU 利用率高，NUMA 会影响性能稳定性

后续可用：

```bash
numactl --hardware
```

## 五、缓存结构（对性能有直接影响）

```text
L1d 缓存： 1.1 MiB
L1i 缓存： 768 KiB
L2 缓存： 30 MiB
L3 缓存： 36 MiB
```

理解方式：

- **L1 / L2：每核或每小组**
- **L3：共享缓存（非常重要）**

📌 这意味着：

- 多线程、向量化、批处理任务友好
- 随机访存、超大对象频繁交换会受限
