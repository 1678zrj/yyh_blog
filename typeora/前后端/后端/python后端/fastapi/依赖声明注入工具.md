## 问：fastapi有哪些依赖注入声明工具

是的！FastAPI 提供了**多个依赖注入声明工具**（也叫“参数声明函数”），它们的作用是告诉 FastAPI：“**这个参数要从哪来、怎么解析、是否必填、是否验证类型**”。

这些工具统一来自 FastAPI 主模块，例如：

```python
from fastapi import Query, Path, Body, Header, Cookie, Form, File, Depends
```

------

## ✅ 常见的依赖注入声明工具一览

| 工具        | 用途 / 数据来源                                  | 常用场景举例         |
| ----------- | ------------------------------------------------ | -------------------- |
| `Query()`   | 从 **URL 查询参数** 中获取（`?name=abc`）        | 分页、搜索等         |
| `Path()`    | 从 **路径参数** 中获取（`/items/{id}`）          | RESTful 接口         |
| `Body()`    | 从 **JSON 请求体** 中获取                        | POST/PUT 接口        |
| `Form()`    | 从 **表单字段**（`x-www-form-urlencoded`）中获取 | 登录表单、非文件表单 |
| `File()`    | 从 **multipart/form-data 文件字段**中获取        | 文件上传             |
| `Header()`  | 从请求 **Header 头部** 中获取                    | Token、User-Agent    |
| `Cookie()`  | 从请求 **Cookie** 中获取                         | 会话管理             |
| `Depends()` | 注入 **依赖函数或类**，自动执行依赖项            | 鉴权、验证、业务复用 |

------

## 🔍 快速示例：各类型使用方式

### ✅ 1. Query 参数

```python
from fastapi import Query

@app.get("/search")
def search(keyword: str = Query(..., min_length=1, max_length=50)):
    return {"q": keyword}
```

------

### ✅ 2. Path 参数

```python
from fastapi import Path

@app.get("/items/{item_id}")
def get_item(item_id: int = Path(..., ge=1)):
    return {"id": item_id}
```

------

### ✅ 3. Body 参数

```python
from fastapi import Body

@app.post("/submit")
def submit(data: dict = Body(...)):
    return {"data": data}
```

------

### ✅ 4. Form 表单

```python
from fastapi import Form

@app.post("/login")
def login(username: str = Form(...), password: str = Form(...)):
    return {"user": username}
```

------

### ✅ 5. File 文件上传

```python
from fastapi import File, UploadFile

@app.post("/upload")
def upload(file: UploadFile = File(...)):
    return {"filename": file.filename}
```

------

### ✅ 6. Header

```python
from fastapi import Header

@app.get("/header")
def read_header(user_agent: str = Header(...)):
    return {"User-Agent": user_agent}
```

------

### ✅ 7. Cookie

```python
from fastapi import Cookie

@app.get("/cookie")
def read_cookie(session_id: str = Cookie(None)):
    return {"session_id": session_id}
```

------

### ✅ 8. Depends（依赖注入系统的核心）

```python
from fastapi import Depends

def verify_token(token: str = Header(...)):
    if token != "secrettoken":
        raise HTTPException(status_code=403)
    return token

@app.get("/secure")
def secure_endpoint(token: str = Depends(verify_token)):
    return {"status": "authorized"}
```

------

## ✅ 总结表格

| 工具      | 来源                  | 典型应用       |
| --------- | --------------------- | -------------- |
| `Query`   | 查询参数 `?q=...`     | 过滤、搜索     |
| `Path`    | 路径参数 `/item/{id}` | 资源 ID        |
| `Body`    | JSON 请求体           | 表单、配置     |
| `Form`    | 表单字段              | 登录、注册     |
| `File`    | 文件字段              | 上传文件       |
| `Header`  | 请求头                | 鉴权、元数据   |
| `Cookie`  | Cookie                | 会话管理       |
| `Depends` | 任意函数或类          | 鉴权、复用逻辑 |

## 🧭 **HTTP 请求方法 × 参数来源 × FastAPI 注入工具** 对照图

```
┌────────────┬────────────────────────────┬──────────────────────────────┐
│ 请求方法   │ 参数来源                   │ FastAPI 注入工具              │
├────────────┼────────────────────────────┼──────────────────────────────┤
│ GET        │ 路径参数 /items/{id}       │ Path()                        │
│            │ 查询字符串 ?key=abc        │ Query()                       │
│            │ 请求头 Header              │ Header()                      │
│            │ Cookie                     │ Cookie()                      │
├────────────┼────────────────────────────┼──────────────────────────────┤
│ POST       │ JSON 请求体                │ Body() / Pydantic 模型        │
│            │ 表单字段                   │ Form()                        │
│            │ 上传文件（multipart）      │ UploadFile + File()           │
│            │ 请求头 Header              │ Header()                      │
│            │ Cookie                     │ Cookie()                      │
├────────────┼────────────────────────────┼──────────────────────────────┤
│ PUT/PATCH  │ JSON 请求体（通常更新）    │ Body() / Pydantic 模型        │
│            │ 路径参数                   │ Path()                        │
│            │ 请求头 / Cookie            │ Header(), Cookie()            │
├────────────┼────────────────────────────┼──────────────────────────────┤
│ DELETE     │ 路径参数                   │ Path()                        │
│            │ 查询参数                   │ Query()                       │
│            │ 请求头 / Cookie            │ Header(), Cookie()            │
└────────────┴────────────────────────────┴──────────────────────────────┘
```

------

## ✅ 图示总结记忆要点：

| 场景                      | 请求方法    | 参数注入方式                        |
| ------------------------- | ----------- | ----------------------------------- |
| 获取数据（只读）          | `GET`       | `Query`, `Path`, `Header`, `Cookie` |
| 提交数据（创建/执行操作） | `POST`      | `Body`, `Form`, `File`, `Header`    |
| 更新数据（全部或部分）    | `PUT/PATCH` | `Body`, `Path`, `Header`            |
| 删除资源                  | `DELETE`    | `Path`, `Query`, `Header`           |

```python
app = FastAPI()

@app.get("/items/{item_id}")
def get_item(
    item_id: int = Path(...),
    q: str = Query(None),
    user_agent: str = Header(None),
    session: str = Cookie(None)
):
    ...

@app.post("/create")
def create_user(data: dict = Body(...)):  # 或者使用 Pydantic 模型
    ...

@app.post("/login")
def login(username: str = Form(...), password: str = Form(...)):
    ...

@app.post("/upload")
def upload(file: UploadFile = File(...)):
    ...
```
