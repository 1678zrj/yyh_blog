## 问：前端发送的请求体与后端接收参数的关系？

这是前后端对接中最关键的一环！我们来系统讲讲：

------

## 一、核心问题：**前端发送的请求体格式，必须与后端的接收方式“对应”起来。否则数据无法解析或报错。**

------

## 二、关系图解

```
前端请求体的格式  ⟶  后端接收方式（视 Content-Type 而定）
─────────────────────────────────────────────
application/json          ⟶   Pydantic 模型（BaseModel）
application/x-www-form-urlencoded ⟶   Form(...) 参数
multipart/form-data       ⟶   Form(...) + File(...)
```

------

## 三、典型格式一览

### ✅ 1. `application/json`

#### 前端（Axios）：

```js
axios.post('/api/data', {
  name: 'Alice',
  age: 25
})
```

默认 `Content-Type: application/json`，请求体是：

```json
{
  "name": "Alice",
  "age": 25
}
```

#### 后端（FastAPI）：

```python
from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int

@app.post("/api/data")
def receive(user: User):
    return user
```

------

### ✅ 2. `application/x-www-form-urlencoded`

#### 前端（URLSearchParams）：

```js
const params = new URLSearchParams()
params.append('name', 'Alice')
params.append('age', '25')

axios.post('/api/form', params)
```

请求体内容（URL 编码）：

```
name=Alice&age=25
```

#### 后端（FastAPI）：

```python
from fastapi import Form

@app.post("/api/form")
def receive(name: str = Form(...), age: int = Form(...)):
    return {"name": name, "age": age}
```

------

### ✅ 3. `multipart/form-data`（用于上传文件）

#### 前端：

```js
const form = new FormData()
form.append('name', 'Alice')
form.append('file', fileInput.files[0])

axios.post('/api/upload', form)
```

#### 后端（FastAPI）：

```python
from fastapi import UploadFile, File, Form

@app.post("/api/upload")
def receive(name: str = Form(...), file: UploadFile = File(...)):
    return {"filename": file.filename}
```

------

## 四、对不上时会发生什么？

| 问题                                         | 说明                            |
| -------------------------------------------- | ------------------------------- |
| 请求体是 JSON，后端却用 Form 接收            | ❌ 会报 422 Unprocessable Entity |
| 请求体是表单，后端用 Pydantic BaseModel 接收 | ❌ 也会报错                      |
| 前端没设置 Content-Type，后端接收失败        | ❌ FastAPI 无法解析体内容        |

------

## 五、总结：

> **请求体格式决定了后端怎么解析，前端发什么格式，后端就必须用相应方式接收。**

| 请求体类型 | 前端发送方式                    | 后端接收方式            |
| ---------- | ------------------------------- | ----------------------- |
| JSON       | axios 直接传对象                | Pydantic `BaseModel`    |
| 表单       | `URLSearchParams()` 或 `<form>` | `Form(...)` 参数        |
| 上传文件   | `FormData()`                    | `Form(...) + File(...)` |
