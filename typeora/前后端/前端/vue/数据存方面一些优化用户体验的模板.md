# ✅ 必要需求 1：登录状态管理（持久化）

### 💾 存储方式：`localStorage`（或 cookie）

### 📦 示例（登录成功后保存）：

```ts
// 登录成功后
localStorage.setItem('token', 'xxxx-token-value');
localStorage.setItem('userInfo', JSON.stringify({ name: '小明', role: 'admin' }));
```

### 🧼 页面加载时自动读取

```ts
const token = localStorage.getItem('token');
if (token) {
  // 设置请求头、跳转首页等
}
```

### ✅ 用户登出时清除：

```ts
localStorage.removeItem('token');
localStorage.removeItem('userInfo');
```

# ✅ 必要需求 2：暗黑模式 / 用户偏好（持久化）

### 💾 存储方式：`localStorage`

### 🌙 示例：切换主题并持久化

```ts
// 监听用户点击切换按钮
function toggleDarkMode() {
  const newTheme = isDark.value ? 'light' : 'dark'
  isDark.value = !isDark.value
  localStorage.setItem('theme', newTheme)
  document.documentElement.setAttribute('data-theme', newTheme)
}
```

### 🎯 页面初始化时读取

```ts
const savedTheme = localStorage.getItem('theme') || 'light';
document.documentElement.setAttribute('data-theme', savedTheme);
```

### 💾 存储方式：`sessionStorage`（仅保留在当前会话）

### 📦 示例：保存分页页码

```ts
function onPageChange(page: number) {
```

### 📦 初始化时恢复：

```ts
const defaultPage = Number(sessionStorage.getItem('tablePage')) || 1;
```

# ✅ 必要需求 4：购物车（使用 Pinia + 持久化）

### 💾 存储方式：`Pinia` + `pinia-plugin-persistedstate`

### 📦 安装插件：

```bash
npm install pinia-plugin-persistedstate
```

### 📦 在 `main.ts` 注册：

```ts
import { createPinia } from 'pinia'
import piniaPluginPersistedstate from 'pinia-plugin-persistedstate'

const pinia = createPinia()
pinia.use(piniaPluginPersistedstate)
app.use(pinia)
```

### 🛒 创建购物车 store（`stores/cart.ts`）：

```ts
import { defineStore } from 'pinia'

export const useCartStore = defineStore('cart', {
  state: () => ({
    cartList: [] as Array<{ id: number; name: string; qty: number }>
  }),
  persist: true  // 一行开启 localStorage 持久化
})
```

### 🎯 使用示例：

```ts
const cartStore = useCartStore()
cartStore.cartList.push({ id: 1, name: '苹果', qty: 2 })
```

```ts
watchEffect(() => {
  localStorage.setItem('formDraft', JSON.stringify(form.value))
```

### 📦 加载时恢复：

```ts
onMounted(() => {

  }
})
```

# ✅ 建议统一封装的工具模块（可复用）

### `utils/storage.ts`

```ts
const prefix = 'myApp_'

export const storage = {
  set(key: string, value: any) {
    localStorage.setItem(prefix + key, JSON.stringify(value))
  },
  get<T>(key: string): T | null {
    const raw = localStorage.getItem(prefix + key)
    return raw ? JSON.parse(raw) as T : null
  },
  remove(key: string) {
    localStorage.removeItem(prefix + key)
  }
}
```

用法：

```ts
storage.set('token', 'abc123')
const token = storage.get<string>('token')
```

# ✅ 必要需求 6：上传文件任务管理（断点续传）

### 📌 场景描述：

- 用户上传多个文件，过程中刷新或意外中断，页面丢失任务信息。
- 上传队列、进度、状态都需要暂存。

------

### 💾 推荐存储方式：`sessionStorage`（仅保留在当前标签页）

### 📦 示例：上传队列持久化

```ts
// 每次变动时保存上传队列（可以放进 watchEffect）
sessionStorage.setItem('uploadQueue', JSON.stringify(uploadList.value));
// 页面刷新后恢复上传任务（如恢复 UI 状态）
const savedQueue = sessionStorage.getItem('uploadQueue');
if (savedQueue) {
  uploadList.value = JSON.parse(savedQueue);
}
```

> 如果你需要断点续传，还需记录分片上传状态，可考虑 `IndexedDB`。

# ✅ 必要需求 7：用户操作记录（最近点击 / 行为日志）

### 📌 场景描述：

- 用户访问页面或点击操作的记录可以用来：
  - 提供“历史记录”模块
  - 上报分析用户行为
  - 辅助推荐系统

------

### 💾 推荐存储方式：`localStorage`（持久化）

### 📦 示例：记录最近操作

```ts
function saveActionRecord(action: string) {
  const records = JSON.parse(localStorage.getItem('userActions') || '[]');
  records.unshift({ action, time: Date.now() });
  // 限制最多 20 条
  localStorage.setItem('userActions', JSON.stringify(records.slice(0, 20)));
}
```

> 页面按钮点击时调用：`saveActionRecord('点击了添加按钮')`

### 📋 使用示例：展示操作历史

```ts
const actions = JSON.parse(localStorage.getItem('userActions') || '[]');
```

# ✅ 必要需求 8：最近访问记录（页面、资源、产品等）

### 📌 场景描述：

- 类似淘宝、B站：“你最近看过的”商品、文章、视频
- 用户离开网站后再次访问，可以回溯之前浏览内容

------

### 💾 推荐存储方式：`localStorage`

### 📦 示例：记录最近访问内容（如页面路径）

```ts
function addRecentVisit(item: { id: string, name: string, url: string }) {
  const list = JSON.parse(localStorage.getItem('recentVisit') || '[]');
  // 去重
  const newList = [item, ...list.filter(i => i.id !== item.id)].slice(0, 10);
  localStorage.setItem('recentVisit', JSON.stringify(newList));
}
```

### 🎯 使用场景：

```ts
onMounted(() => {
  addRecentVisit({
    id: route.params.id,
    name: articleTitle.value,
    url: route.fullPath
  });
})
```

### 📋 页面中展示：

```ts
const recent = JSON.parse(localStorage.getItem('recentVisit') || '[]');
```
