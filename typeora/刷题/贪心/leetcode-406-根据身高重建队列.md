# 题目描述：

假设有打乱顺序的一群人站成一个队列，数组 `people` 表示队列中一些人的属性（不一定按顺序）。每个 `people[i] = [hi, ki]` 表示第 `i` 个人的身高为 `hi` ，前面 **正好** 有 `ki` 个身高大于或等于 `hi` 的人。

请你重新构造并返回输入数组 `people` 所表示的队列。返回的队列应该格式化为数组 `queue` ，其中 `queue[j] = [hj, kj]` 是队列中第 `j` 个人的属性（`queue[0]` 是排在队列前面的人）。

**示例 1：**

```
输入：people = [[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]
输出：[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]
解释：
编号为 0 的人身高为 5 ，没有身高更高或者相同的人排在他前面。
编号为 1 的人身高为 7 ，没有身高更高或者相同的人排在他前面。
编号为 2 的人身高为 5 ，有 2 个身高更高或者相同的人排在他前面，即编号为 0 和 1 的人。
编号为 3 的人身高为 6 ，有 1 个身高更高或者相同的人排在他前面，即编号为 1 的人。
编号为 4 的人身高为 4 ，有 4 个身高更高或者相同的人排在他前面，即编号为 0、1、2、3 的人。
编号为 5 的人身高为 7 ，有 1 个身高更高或者相同的人排在他前面，即编号为 1 的人。
因此 [[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]] 是重新构造后的队列。
```

**示例 2：**

```
输入：people = [[6,0],[5,0],[4,0],[3,2],[2,2],[1,4]]
输出：[[4,0],[5,0],[2,2],[3,2],[1,4],[6,0]]
```

 

**提示：**

- `1 <= people.length <= 2000`
- `0 <= hi <= 106`
- `0 <= ki < people.length`
- 题目数据确保队列可以被重建





## 原解法：

```python
class Solution:
    def reconstructQueue(self, people: List[List[int]]) -> List[List[int]]:
        sorted_people = sorted(people, key=lambda x: (-x[0], x[1]))
        for index,people in enumerate(sorted_people.copy()):
            high = people[0]
            num = people[1]
            cha = index - num
            if cha == 0:
                continue
            for i in range(cha):
                sorted_people[index-i] = sorted_people[index-1-i] 
            sorted_people[index-cha] = [high,num]
        print(sorted_people)
        return sorted_people

```

时间复杂度：0(n^2)

思想：按照身高从高到低排序、身高相同的按照前面身高大于或等于自身的人数从小到大排序，这个操作就是将前面身高大于或等于自身的人数最大化，此时每向前移动一个位置，前面身高大于或等于自身的人数就会减一，也就是说看当前index和原来的顺序中ki的差值，根据这个差值来判断要向前移动几格。

由于你的身高本来就小于等于你身前的所有人，因此你的移动是不会改变其它人的ki的，只会对你自己的ki造成变化，而你前面的第一个人一直到你的新的位置的那一队人的位置只要依次向后移动一格即可，且这队人的相对位置保持不变，使得他们的ki不会变化。



改进解法：

思路

## 1、排序策略：

先按身高 h从高到低排序，若身高相同，则按 k从小到大排序。

拍完序后依次遍历加入新的队列，这样可以保证：当我们处理到某个人时，无论将他排在新队列的哪里，他所处的位置只会影响他自己的计数。新队列中已经存在的所有人都比他高或等高，不会影响新队列中已经存在的任何人“前方有 k 个身高 ≥ 自己的人”的计数。

## 2、插入策略：

按排序后的顺序，依次将每个人插入到结果队列的索引 k 处。

因为此时队列中所有人都比他高，所以直接插入到 k 位置，就能保证他前面正好有 k 个更高或等高的人。

## 3、核心思想：

高个子先排好，他们的相对顺序不会再被矮个子影响；

矮个子插入时，只需根据自己的 k 位置插入，因为他们不会影响比自己高的人的“前面有多少个更高的人”计数。

## 解题过程

输入：

```
[[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]
```

 排序后：

```
[[7,0],[7,1],[6,1],[5,0],[5,2],[4,4]]
```

 插入过程如下：

```
[7,0]

[7,0],[7,1]

[7,0],[6,1],[7,1]

[5,0],[7,0],[6,1],[7,1]

[5,0],[7,0],[5,2],[6,1],[7,1]

[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]
```



```
class Solution:
    def reconstructQueue(self, people: List[List[int]]) -> List[List[int]]:
        sorted_people = sorted(people, key=lambda x: (-x[0], x[1]))
        queue = []
        for people in sorted_people:
            queue.insert(people[1],people)
        return queue
```
