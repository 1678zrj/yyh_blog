### 问：Python列表表达式能使用双重循环吗

**可以的，Python 的列表推导式（List Comprehension）完全支持双重循环（甚至多重循环）。**

在列表推导式中使用双重循环时，它的执行顺序和普通的嵌套 `for` 循环是一模一样的：**前面的 `for` 是外层循环，后面的 `for` 是内层循环。**

### 基本语法

Python

```
[表达式 for 外层变量 in 外层序列 for 内层变量 in 内层序列]
```

### 常见应用场景示例

#### 1. 将二维列表（矩阵）展平为一维列表

这是最常见的使用场景之一。

Python

```
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

# 使用双重循环的列表推导式
flattened = [num for row in matrix for num in row]

print(flattened)
# 输出: [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

> **理解方式**：它完全等价于以下常规代码：
>
> Python
>
> ```
> flattened = []
> for row in matrix:         # 外层循环
>     for num in row:        # 内层循环
>         flattened.append(num)
> ```

#### 2. 生成全排列 / 笛卡尔积

当你需要组合两个不同列表中的元素时：

Python

```
colors = ['红', '蓝']
sizes = ['S', 'M', 'L']

# 生成所有颜色和尺寸的组合
combinations = [f"{color}-{size}" for color in colors for size in sizes]

print(combinations)
# 输出: ['红-S', '红-M', '红-L', '蓝-S', '蓝-M', '蓝-L']
```

#### 3. 带有条件判断（if）的双重循环

你还可以在双重循环后面加上 `if` 语句来进行过滤。

Python

```
list1 = [1, 2, 3]
list2 = [3, 4, 5]

# 找出 list1 和 list2 中相同的元素组合（这里只是演示语法，找交集通常用 set）
pairs = [(x, y) for x in list1 for y in list2 if x == y]

print(pairs)
# 输出: [(3, 3)]
```

### 💡 小建议

虽然列表推导式支持多重循环，但为了**代码的可读性**，一般建议最多使用两层。如果达到三层或以上，或者内部逻辑非常复杂，改写成传统的 `for` 循环结构会让代码更容易维护和阅读。

### 问：在双重循环中，如果外层循环也带有if判断，这个if判断的结果是决定是否进行内层循环的吗

**是的，完全正确！**

在列表推导式中，`if` 语句的位置决定了它的作用范围。如果你将 `if` 判断紧跟在**外层循环**的后面，它就会在进入**内层循环**之前进行拦截。也就是说，只有满足外层 `if` 条件的元素，才会开启内层循环。

我们可以通过一个具体的例子来看看它是如何工作的。

### 语法结构对比

当你这样写列表推导式时：

Python

```
[表达式 for x in 外层列表 if 外层条件 for y in 内层列表]
```

它在底层完全等价于下面这个传统的嵌套循环：

Python

```
result = []
for x in 外层列表:
    if 外层条件:            # <--- 你的理解完全正确，它在这里拦截！
        for y in 内层列表:
            result.append(表达式)
```

### 具体代码示例

假设我们有一个数字列表和一个字母列表，我们只想把**偶数**和所有字母进行组合。

Python

```
numbers = [1, 2, 3, 4]
letters = ['A', 'B']

# 外层循环自带 if 判断
result = [f"{n}{l}" for n in numbers if n % 2 == 0 for l in letters]

print(result)
# 输出: ['2A', '2B', '4A', '4B']
```

**执行逻辑分析：**

1. 取出 `1`，判断 `1 % 2 == 0` 为假，直接跳过（**不进入内层字母循环**）。
2. 取出 `2`，判断为真，进入内层循环，生成 `'2A'` 和 `'2B'`。
3. 取出 `3`，判断为假，直接跳过。
4. 取出 `4`，判断为真，进入内层循环，生成 `'4A'` 和 `'4B'`。

### 💡 进阶：双层循环双层过滤

你甚至可以在外层和内层循环后面各加一个 `if`，互不干扰：

Python

```
# 只组合：外层是偶数，且内层是'B'的情况
[f"{n}{l}" for n in numbers if n % 2 == 0 for l in letters if l == 'B']
# 输出: ['2B', '4B']
```

总结来说，列表推导式的读取顺序是从左到右的，`if` 放在哪个 `for` 后面，它就负责过滤那个 `for` 产生的变量，非常符合直觉。
