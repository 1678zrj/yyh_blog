## python如何根据文件名获取文件后缀？

### GPT:

在 Python 中，可以使用标准库 `os.path` 或 `pathlib` 获取文件名的后缀（扩展名）。以下是两种常用方法：

------

### 方法一：使用 `os.path.splitext`

```python
import os

filename = "example.docx"
# 分离文件名和扩展名
name, ext = os.path.splitext(filename)
print(ext)  # 输出: .docx
```

> 注意：返回的扩展名前面包含一个点（`.`）。

------

### 方法二：使用 `pathlib.Path.suffix`

```python
from pathlib import Path

filename = "example.docx"
ext = Path(filename).suffix
print(ext)  # 输出: .docx
```

------

### 如果你只想要不带点的后缀名：

```python
ext = Path(filename).suffix.lstrip(".")
print(ext)  # 输出: docx
```

------

这两种方法都可以，推荐使用 `pathlib`，因为它更现代、功能更强大且代码更清晰。需要 Python 3.4 及以上版本。
