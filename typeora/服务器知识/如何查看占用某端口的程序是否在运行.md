你可以通过以下几种方法查看服务器上是否有程序正在监听或使用端口号 `4000`：

------

### ✅ 方法一：使用 `lsof` 命令（推荐）

```bash
sudo lsof -i :4000
```

- 如果有程序占用了该端口，会显示该程序的详细信息（进程名、PID 等）。
- 没有输出则说明端口未被使用。

------

### ✅ 方法二：使用 `netstat` 命令（旧系统常用）

```bash
sudo netstat -tuln | grep :4000
```

- 显示的格式大致如下：

  ```
  tcp        0      0 0.0.0.0:4000          0.0.0.0:*               LISTEN
  ```

> 说明有程序正在监听 `4000` 端口。

------

### ✅ 方法三：使用 `ss` 命令（更现代、更快）

```bash
sudo ss -tuln | grep :4000
```

- 输出类似于：

  ```
  LISTEN     0      128    0.0.0.0:4000       0.0.0.0:*
  ```

------

### ✅ 方法四：配合查看对应进程

你还可以结合 `ps` 来查看具体是哪个程序运行了这个端口：

```bash
sudo lsof -i :4000
```

结果中会显示 `PID`，然后你可以进一步查看进程详情：

```bash
ps -p <PID> -f
```

------

### 💡补充：如果你想持续监听某端口的变化

```bash
watch -n 1 "lsof -i :4000"
```
