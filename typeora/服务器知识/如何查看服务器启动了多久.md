你可以使用以下几种方式查看服务器“开机时间”或“已经运行了多久”：

------

### ✅ 方法一：使用 `uptime` 命令（最简单）

```bash
uptime
```

输出示例：

```
 15:23:01 up 3 days,  4:12,  2 users,  load average: 0.01, 0.05, 0.03
```

> 说明系统已经运行了 **3 天 4 小时 12 分钟**。

------

### ✅ 方法二：使用 `who -b` 查看最后一次启动时间

```bash
who -b
```

输出示例：

```
         system boot  2025-05-29 11:10
```

> 表示系统最近一次开机是在 **2025年5月29日 11:10**。

------

### ✅ 方法三：查看 `/proc/uptime`（精确到秒）

```bash
cat /proc/uptime
```

输出类似：

```
274520.55 234.12
```

- 第一个数字是系统从启动到现在的总秒数（274520 秒约为 3 天 4 小时）。
- 第二个数字是空闲时间，可忽略。

你可以用 `awk` 或 Python 转换它：

```bash
awk '{printf("Uptime: %d days, %02d:%02d:%02d\n", $1/86400, ($1%86400)/3600, ($1%3600)/60, int($1%60))}' /proc/uptime
```

------

### ✅ 方法四：使用 `top` 命令（顶部信息）

```bash
top
```

在第一行通常会看到类似：

```
top - 15:26:30 up 3 days,  4:16,  2 users,  load average: 0.00, 0.03, 0.05
```
