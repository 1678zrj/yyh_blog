### 从服务器上下载文件到我自己的电脑上，应该使用什么命令？

要从服务器下载文件到你自己的电脑上，常用的方法取决于你的操作系统（Windows、macOS 或 Linux）和你是否能通过 SSH 连接服务器。下面列出几种常见的方法：

------

### ✅ **方法一：使用 `scp` 命令（适用于 Linux/macOS/Windows（通过 WSL 或安装了 OpenSSH））**

```bash
scp username@server_ip:/path/to/remote/file /path/to/local/directory
```

- `username`：服务器用户名
- `server_ip`：服务器 IP 地址或域名
- `/path/to/remote/file`：服务器上的文件路径
- `/path/to/local/directory`：你电脑上的保存路径

📌 **示例**：

```bash
scp user@192.168.1.100:/home/user/data.zip ~/Downloads/
```

------

### ✅ **方法二：使用 `rsync`（高效支持断点续传）**

```bash
rsync -avz username@server_ip:/remote/path /local/path
```

------

### ✅ **方法三：使用 `WinSCP`（适用于 Windows）**

1. 下载并安装 [WinSCP](https://winscp.net/eng/download.php)
2. 输入服务器地址、用户名、密码（或 SSH 密钥）
3. 使用图形界面拖拽下载文件

------

### ✅ **方法四：使用 `sftp` 命令（类似 FTP，但基于 SSH）**

```bash
sftp username@server_ip
```

然后在交互式终端中：

```bash
cd /remote/path/to/file
get filename
```

退出 SFTP：

```bash
exit
```

------

### ⚠️ 补充提示

- 如果你使用密钥认证，可能需要加 `-i` 参数，例如：

  ```bash
  scp -i ~/.ssh/id_rsa user@server:/path/file .
  ```

- 有防火墙或权限限制时，确保服务器开启了 SSH 并允许访问。

### scp命令是什么协议？

`scp` 命令使用的是 **SSH（Secure Shell）协议**，它是基于 SSH 的文件拷贝工具。

------

### 🔍 详细说明：

- **协议类型**：`scp` 使用 **SSH 协议（端口号默认是 22）**
- **安全性**：数据传输是加密的，包括用户名、密码和文件内容
- **认证方式**：
  - 可以使用用户名+密码
  - 也可以使用 SSH 密钥进行无密码认证

------

### 📌 对比其他文件传输协议：

| 工具/协议      | 使用的底层协议 | 是否加密 | 特点                                |
| -------------- | -------------- | -------- | ----------------------------------- |
| `scp`          | SSH            | ✅ 是     | 适合简单的命令行文件传输            |
| `sftp`         | SSH            | ✅ 是     | 更适合交互式操作，命令类似 FTP      |
| `rsync` (远程) | SSH            | ✅ 是     | 支持断点续传、增量传输              |
| `ftp`          | FTP            | ❌ 否     | 明文传输，安全性差                  |
| `ftps`         | FTP+SSL/TLS    | ✅ 是     | FTP 的加密版，设置稍复杂            |
| `http`/`https` | HTTP/HTTPS     | ❌ / ✅    | 浏览器下载文件或 `wget`/`curl` 下载 |
| `WinSCP`       | SSH/SFTP/FTP   | ✅ / ❌    | Windows 图形化传输工具，支持多协议  |

------

### ✅ 总结：

> `scp` = **基于 SSH 协议的安全文件复制命令**。
>  它的优点是安全、简单、无需额外设置，非常适合从一台机器远程下载或上传文件。

如果你需要传输大量文件、支持断点续传等，`rsync` 是更高级的替代方案。需要图形界面的话，可以用 `WinSCP` 或 `FileZilla`。

### 命令执行完毕后会断开连接吗?

是的，**`scp` 命令在文件传输完成后会自动断开与远程服务器的连接**。

------

### ✅ 更详细说明：

- `scp` 是一个**一次性执行的命令**，不像 `ssh` 那样维持一个交互式会话。
- 执行流程是：
  1. 建立 SSH 连接；
  2. 传输文件（显示进度条）；
  3. 一旦传输完成，立即断开连接；
  4. 命令终止，回到你本地终端。

------

### ✅ 示例：

```bash
scp -r zzj@10.18.19.47:/home/zzj/project_reports ./
```

执行完后你会看到类似的输出：

```
project_reports/file1.txt                                100%  14KB  1.2MB/s   00:00    
project_reports/file2.pdf                                100% 2.1MB  4.3MB/s   00:01
```

接着命令行就会返回到本地 shell 提示符：

```bash
yourname@yourmachine:~$
```

------

### ⛔ 不会留下什么：

- 不会保持登录状态
- 不会在后台挂着连接
- 不需要你手动 `exit`

------

### ✅ 如果你想保持会话，可以使用：

- `ssh zzj@10.18.19.47`：进入远程交互式终端
- 或者使用 `sftp` 命令进行多次传输、交互式会话

### 我还有个疑问，就是以上命令无论是接收文件还是上传文件，都没有指定端口号，如果连接服务器的端口号不是22呢

你的这个问题问得非常专业，👍确实，如果服务器的 SSH 端口号不是默认的 `22`，那么你 **必须手动指定端口号**，否则连接会失败。

## ✅ `scp` 指定端口的方式：使用 `-P`（注意是大写的 P）

```bash
scp -P 端口号 [源路径] [用户名]@[IP地址]:[目标路径]
```

------

## 🔁 举例说明

### 🔽 1. 下载文件（从远程拉到本地）

```bash
scp -P 2222 zzj@10.18.19.47:/home/zzj/report.pdf ./
```

表示从端口 `2222` 连接远程主机，然后下载 `report.pdf` 到当前目录。

------

### 🔼 2. 上传文件（从本地推到远程）

```bash
scp -P 2222 ./report.pdf zzj@10.18.19.47:/home/zzj/
```

表示通过端口 `2222` 上传本地 `report.pdf` 到服务器的 `/home/zzj/` 目录。

------

## ⚠️ 注意事项

- `-P` 是 **大写**，不是小写的 `-p`，后者表示保留文件的时间戳等属性。

- 不支持使用 `scp` 的时候通过地址写 `IP:port` 的方式，例如下面这样是错误的：

  ```bash
  ❌ scp zzj@10.18.19.47:2222:/path/to/file ./
  ```

------

## ✅ 小总结

| 操作                     | 命令模板                                       |
| ------------------------ | ---------------------------------------------- |
| 下载（从远程复制到本地） | `scp -P 端口 用户@远程IP:/远程路径 ./本地路径` |
| 上传（从本地复制到远程） | `scp -P 端口 ./本地路径 用户@远程IP:/远程路径` |

------

```bash

```

这就说明你需要用 `-P 2222`。

### 连接有些服务器的端口号不是22，这些服务器是怎么修改的

非常好的问题！当某些服务器**不使用默认的 22 端口来提供 SSH 服务**时，通常是**出于安全性考虑**（比如避免被扫描和暴力破解）。这种修改是在服务器上通过配置 SSH 服务的配置文件实现的。

------

## ✅ 如何修改 SSH 的默认端口号（以 Linux 服务器为例）

1. **编辑 SSH 配置文件**

   打开服务器上的配置文件（需要 root 权限）：

   ```bash
   sudo nano /etc/ssh/sshd_config
   ```

2. **修改或添加 `Port` 字段**

   找到或添加这一行（假设改为 `2222`）：

   ```bash
   Port 2222
   ```

   如果有多余的 `Port 22` 行，也可以注释掉：

   ```bash
   #Port 22
   Port 2222
   ```

3. **（可选）确保防火墙放行新的端口**

   比如用 `ufw`（Ubuntu）：

   ```bash
   sudo ufw allow 2222/tcp
   ```

4. **重启 SSH 服务**

   ```bash
   sudo systemctl restart sshd
   ```

5. **测试新端口是否可用**

   在客户端用 `ssh -p 2222` 或 `scp -P 2222` 连接测试。

------

## 📌 查看服务器当前 SSH 端口

你可以在服务器上运行：

```bash
sudo grep ^Port /etc/ssh/sshd_config
```

或查看监听端口：

```bash
sudo netstat -tlnp | grep ssh
# 或
sudo ss -tlnp | grep ssh
```

------

## 🚨 注意事项

- 改端口前一定要先**放行新端口的防火墙规则**，不然 SSH 会被锁死，远程登录不了。

- 更改端口后，以后连接必须显式指定端口，比如：

  ```bash
  ssh -p 2222 username@your.server.ip
  scp -P 2222 file username@your.server.ip:/path/
  ```
